# Job 489029d8 — UX Importação CLW2 (tabs + diff)

## O que mudou

1. **Médicos não vêm mais pré-selecionados.** A lista inicia vazia; o botão “Selecionar piloto (3)” continua disponível se quiser.
2. **Report útil:** em vez de stats genéricos + JSON de “Sinais”, o report mostra:
   - resumo compacto só com contagens > 0 (rótulos em português);
   - abas **Pacientes** e **Receitas**;
   - lista do que será importado (ação, nome, subtítulo);
   - ao clicar: **diff campo a campo** (Atual CLW3 → Depois legado);
   - navegação **Anterior / Próximo** (também ← → no teclado).
3. Backend passa a gravar `changes.pacientes` / `changes.receitas` no `report-latest.json` (com before/after/diff). A UI carrega a lista e o detalhe via API (não embute o JSON gigante no HTML do Inertia).

## Arquivos

- `app/Services/Migration/LegadoIncrementalImporter.php` — coleta `change` por paciente/receita
- `app/Http/Controllers/Tools/ImportacaoClw2Controller.php` — `slimReport` + endpoints JSON

## Como validar

1. Abrir https://revski-main.ddev.site:33177/tools/importacao-clw2 (admin).
2. Confirmar que **nenhum médico** está marcado ao abrir a página.
3. Selecionar médicos (ou “Selecionar piloto”), rodar **Dry-run** de novo.
   - Importante: reports antigos **não** têm `changes`; precisa de um dry-run novo.
4. No report: abas Pacientes / Receitas → clicar um item → ver diff → usar Anterior/Próximo.
