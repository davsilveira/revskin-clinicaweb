## ⚠️ Ação pendente do lado do usuário (troca de .env)
Para que TODAS as páginas (inclusive o título padrão renderizado pelo servidor) mostrem
**ClinicaWeb** em vez de **Revskin**, altere no `.env` de produção:

```env
APP_NAME="ClinicaWeb"
```

Depois rode no servidor (ou deixe o próximo deploy/`hostinger-post-deploy.sh` fazer):

```bash
php artisan config:clear && php artisan config:cache
```

Observações:
- O sufixo client-side já é `ClinicaWeb` independentemente do `.env`, porque o build do CI
  não define `VITE_APP_NAME` e agora cai no fallback `'ClinicaWeb'` (antes era
  `'Laravel Boilerplate'`).
- `VITE_APP_NAME` é embutido em tempo de build (no CI), então mudar o `.env` do servidor não
  afeta o bundle — só o `APP_NAME` (config) afeta o título server-side.

## Como validar manualmente
1. Abra https://clinicaweb.revskin.com.br/, faça login e navegue por várias páginas.
2. Observe o título da aba: não deve mais aparecer "Laravel Boilerplate" em nenhuma página.
3. Após ajustar `APP_NAME="ClinicaWeb"` no `.env` de produção, o título padrão
   (páginas sem título próprio) muda de "Revskin" para "ClinicaWeb".
