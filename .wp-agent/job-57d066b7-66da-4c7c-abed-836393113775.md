## O que o perfil Call Center (`role = callcenter`) acessa hoje

Fonte: `routes/web.php`, `app/Http/Middleware/EnsureUserIsCallcenter.php`, `app/Models/User.php`, `app/Http/Controllers/ReceitaController.php`.

### Receitas
- `GET /receitas` — listagem (index). **Não** é filtrada por médico para o Call Center (só médicos têm filtro em `ReceitaController@index`, linha ~46). Portanto o Call Center **vê todas as receitas**.
- `GET /receitas/{receita}` — visualização (show).
- `GET /receitas/{receita}/pdf` — **download do PDF**.
- `POST /receitas/{receita}/copiar` e `POST /receitas/{receita}/finalizar`.
- **Não pode**: criar, editar, atualizar, excluir, cancelar-e-duplicar (restrito a médico/admin — bloqueado com `isCallcenter() → abort(403)`).

### Atendimentos Call Center
- `GET /callcenter`, `GET /callcenter/{atendimento}`, atualizar status, adicionar acompanhamento, cancelar múltiplos.

### Produtos

## Ponto-chave para a demanda do cliente
`User::canAccessPaciente()` (app/Models/User.php:200) já retorna `true` para admin **e** Call Center:

```php
if ($this->isAdmin() || $this->isCallcenter()) {
    return true;
}
```

Como `show` e `pdf` só validam `canAccessPaciente($receita->paciente)`, o Call Center **já tem acesso a qualquer receita e já pode baixar o PDF** de qualquer receita (inclusive finalizadas/fechadas). Não há restrição por médico/clínica para esse perfil.
