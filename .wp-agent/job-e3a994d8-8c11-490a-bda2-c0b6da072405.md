# Job e3a994d8 — tabs Pacientes/Receitas vazias

## Causa
O `report_hash` é o MD5 do dump SQL e **não muda** entre dry-runs. O fetch da lista dependia só do hash: após um dry-run novo (com `changes`), o painel reusava a lista vazia carregada do report antigo.

## Correção
- `useEffect` agora depende de `hash + generated_at`
- query `?t=generated_at` + `Cache-Control: no-store` na API

## Validação
Playwright em `/tools/importacao-clw2`: lista com **218** pacientes; API 200 com `p=218`.

Recarregar a página (ou novo dry-run) basta para ver a lista.
