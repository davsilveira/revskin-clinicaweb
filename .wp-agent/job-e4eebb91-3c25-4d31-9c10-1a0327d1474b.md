# Worklog — Título da aba nas páginas sem nome ("- ClinicaWeb")

## Problema
As páginas **Relatórios**, **Tabela Karnaugh**, **Regras Condicionais** e **Receita (view/edit)**
não definiam título de página. A aba do navegador mostrava apenas `- ClinicaWeb` (o sufixo do
template do Inertia `"<título> - <appName>"` com o título vazio).

## Causa raiz
- Várias páginas faziam `<DashboardLayout title="...">`, mas o `DashboardLayout` só recebia
  `{ children }` — o prop `title` era **ignorado** (nenhum `<Head>` renderizado).
- Outras páginas (Relatórios, Receita view/edit) não passavam título nenhum.

O padrão correto no projeto é `<Head title="..." />` (ex.: `Pacientes/Index.jsx`).

## Alterações
1. **`resources/js/Layouts/DashboardLayout.jsx`**
   - Importa `Head` do `@inertiajs/react`.
   - Assinatura passa a aceitar o prop: `DashboardLayout({ children, title })`.
   - Renderiza `{title && <Head title={title} />}` no topo do layout.
   - Isso já corrige automaticamente as páginas que **já** passavam `title`:
     - `AssistenteReceita/TabelaKarnaughView.jsx` → `Tabela: <nome>`
     - `AssistenteReceita/RegrasCondicionais.jsx` → `Regras Condicionais`
     - `AssistenteReceita/TabelasKarnaugh.jsx` → `Tabelas Karnaugh`
2. **`resources/js/Pages/Relatorios/Index.jsx`** → `title="Relatórios"`
3. **`resources/js/Pages/Relatorios/ReceitasMedico.jsx`** → `title="Receitas por Médico"`
4. **`resources/js/Pages/Relatorios/AquisicaoProdutos.jsx`** → `title="Aquisição de Produtos"`
5. **`resources/js/Pages/Receitas/Show.jsx`** (view) →
   `title={tituloReceitaComSequencia('Receita', receita.numero)}` (ex.: "Receita Nº 2")
6. **`resources/js/Pages/Receitas/Form.jsx`** (create/edit) →
   - Nova: `"Nova Receita"`
   - Edição: `"Editar Receita Nº N"`
   - Modo visualização dentro do form: `"Receita Nº N"`

Não há conflito de título: as páginas que já usam o próprio `<Head>` não passam `title` ao
layout, então o `<Head>` do layout só é renderizado quando o prop é fornecido.

## Como validar manualmente
1. Acesse https://clinicaweb.revskin.com.br/ e faça login.
2. Navegue (via cliques dentro do app, para exercitar o título client-side do Inertia) até:
   - **Relatórios** (`/relatorios`) → aba: "Relatórios - ClinicaWeb"
   - **Receitas por Médico** (`/relatorios/receitas-medico`) → "Receitas por Médico - ClinicaWeb"
   - **Aquisição de Produtos** → "Aquisição de Produtos - ClinicaWeb"
   - **Tabela Karnaugh** (abrir uma tabela) → "Tabela: <nome> - ClinicaWeb"
   - **Regras Condicionais** → "Regras Condicionais - ClinicaWeb"
   - **Receita – visualizar** (abrir uma receita) → "Receita Nº N - ClinicaWeb"
   - **Receita – editar / nova** → "Editar Receita Nº N" / "Nova Receita" + " - ClinicaWeb"
3. Confirme que nenhuma dessas abas mostra apenas "- ClinicaWeb".

_Observação: o título é definido no client (JS/Inertia); um `curl` mostra apenas o título
padrão renderizado pelo servidor, então a validação precisa ser feita no navegador._
